# Sales Forecasting System

## Data Science Internship – Sqrock IT Solutions

### Project Overview
This project predicts future sales using Machine Learning. Historical monthly sales data is analyzed to identify trends and forecast upcoming sales. A Linear Regression model is used to make future sales predictions.

---

## Objective
- Analyze historical sales data.
- Understand monthly sales trends.
- Build a Machine Learning model for sales forecasting.
- Predict future sales.

---

## Tools & Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

---

## Dataset
**Dataset Name:** Monthly Car Sales Dataset

**Columns:**
- Month
- Sales

---

## Project Workflow
1. Import required libraries.
2. Load the dataset.
3. Explore and analyze the data.
4. Convert the Month column into Date format.
5. Create Year and Month_Number features.
6. Split the dataset into training and testing data.
7. Train the Linear Regression model.
8. Predict sales.
9. Evaluate the model using MAE and RMSE.
10. Forecast future sales.

---

## Model Used
**Linear Regression**

---

## Model Evaluation
- MAE (Mean Absolute Error): **2238.88**
- RMSE (Root Mean Squared Error): **2754.68**
